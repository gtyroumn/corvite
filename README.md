# Corvite

[Русский](README.md) · [Українська](README.uk.md) · [English](README.en.md)

Оптимизатор Windows 11 для игр: безопасные твики системы, сети, памяти и фоновых служб, профили с оценкой риска, подсказки по таймингам ОЗУ и локальный советник Corvi. Всё, что программа меняет, можно вернуть. Лицензия MIT.

## Установка
1. Скачайте `Corvite-Setup.exe` (или portable zip) со страницы [Releases](https://github.com/gtyroumn/corvite/releases) и запустите. Нужна Windows 11 x64, права администратора.
2. Windows SmartScreen может написать «Windows защитила ваш компьютер» и «неизвестный издатель»: у проекта нет платной подписи кода. Нажмите «Подробнее», затем «Выполнить в любом случае».
3. При первом запуске выберите ПК или ноутбук. Программа сохранит резервную копию исходных настроек ещё до любых изменений.

## Важно знать
- Изменения сначала только отмечаются и применяются кнопкой «Применить». Красная зона требует подтверждения.
- Вы меняете настройки системы на свой риск. Разгонные параметры могут повышать нагрев и приводить к сбоям; на ноутбуках пределы ужесточены. Значения прироста FPS ориентировочные.
- Программа не ставит драйверы и не обходит защиту системы. Лимиты и напряжение процессора и часть настроек видеокарты программа сама не пишет: для них есть руководства со значениями и кнопкой запуска официальной программы (см. «Руководства по подбору значений»).

## Откат и удаление
- «Отменить изменения» (внизу) сбрасывает неприменённое, «Вернуть предыдущие настройки» отменяет последнее применение.
- «Обзор», «Вернуть исходные настройки» возвращает всё к состоянию первого запуска. Копия лежит в `%ProgramData%\Corvite\Backups`.
- Удалить можно через «Параметры», «Приложения»: окно удаления предлагает вернуть настройки к исходным. Папка `%ProgramData%\Corvite` (копия, журнал, настройки) остаётся: удалите её вручную, если она не нужна.

## Для разработчиков: сборка (на Windows 11, нужен .NET 8 SDK)
```
dotnet build Corvite.sln -c Release
```
Запуск (приложению нужны права администратора, из обычной консоли `dotnet run` не работает, ошибка 740):
```
Start-Process "src\Corvite.App\bin\Release\net8.0-windows10.0.22000.0\Corvite.exe" -Verb RunAs
```
Отладочный режим с демо-конфигурациями железа (6 конфигураций из прототипа на вкладке «Железо и частоты»):
```
Start-Process "src\Corvite.App\bin\Release\net8.0-windows10.0.22000.0\Corvite.exe" -ArgumentList "--demo" -Verb RunAs
```

> ⚠ Код написан без компиляции в среде разработки (нет .NET SDK). Этап 1 собран и проверен пользователем. Этапы 2 и 3 ещё не проверялись: возможны мелкие ошибки сборки.

## Датчики (этап 2)
Температура и частоты берутся из LibreHardwareMonitor. На части систем драйвер доступа к процессору заблокирован Windows или антивирусом: тогда температура CPU берётся из ACPI-зоны (на некоторых ноутбуках её нет) или показывается «—». Загрузка и ОЗУ работают без драйвера.

## Структура
- `src/Corvite.Core`: каталог параметров (`TweakCatalog.g.cs`, **генерируется** из прототипа), движок профилей/риска/эффекта (`ProfileEngine`), данные (`Data/*.json`: игры, тайминги ОЗУ, демо-железо).
- `src/Corvite.Hardware`: `HardwareDetector` (WMI: CPU, GPU, ОЗУ, плата, диск, ПК/ноутбук) и `SensorService` (LibreHardwareMonitor, ОЗУ, ACPI).
- `src/Corvite.App`: WPF, тема (`Theming/Theme.xaml`), шаблоны строк и страниц (`Views/Templates.xaml`), ViewModels, локализация (`Resources/Strings*.resx`, `Localization/Loc.cs`).
- `tools/gen.js`: перегенерирует каталог и `.resx` из `tools/prototype.html` (`node tools/gen.js tools/prototype.html .`).

Шрифты (Tektur, IBM Plex Sans, JetBrains Mono) нужно положить в `src/Corvite.App/Assets/Fonts` (см. README там).

## Этап 3: запись в Windows
- Приложение требует администратора. При первом запуске создаётся `%ProgramData%\Corvite\Backups\baseline.json` (исходные значения) до любых изменений.
- Перед первым применением за сеанс создаётся точка восстановления Windows (Windows разрешает одну в 24 часа, ошибка не критична).
- «Вернуть предыдущие настройки» откатывает последнее применение; «Вернуть исходные настройки» берёт baseline. Логи: `%ProgramData%\Corvite\Logs\corvite.log`.
- Безопасная проверка интерфейса без записи в систему: запуск с ключом `--dry-run`.
- Авто-откат: две подряд замеры CPU/GPU выше порога в течение 15 минут после применения отменяют последнее применение.
- Параметры защиты (порог, переключатели) сохраняются между запусками.
- «История применений» (кнопка в шапке) позволяет вернуться к любому шагу, а не только на один назад. «Экспорт» и «Импорт» на вкладке профилей переносят настройки между ПК одним файлом.

## Во время игры (этап 4)
Список программ для «Закрывать фоновые приложения» лежит в `%ProgramData%\Corvite\kill-list.txt` (создаётся при первом запуске игры, по одному имени процесса в строке, `#` отключает строку). Закрытые программы запускаются снова после игры. Лимит фоновой нагрузки понижает приоритет чужих программ (до 24 % «ниже обычного», с 25 % «простой»), после игры приоритеты возвращаются. Если приложение закрылось аварийно во время игры, при следующем запуске оно вернёт службы и уведомления.

## Этап 5: что сделано и что нет
- **NVIDIA (NVML, `nvml.dll` из драйвера):** `gpow`, `gcore`, `gmem`. Настройки NVML сбрасываются после перезагрузки или перезапуска драйвера. Смещение памяти считается в «эффективных» МГц, как в MSI Afterburner (в NVML вдвое меньше). На многих ноутбуках драйвер запрещает такие изменения: тогда строка остаётся серой «недоступно».
- **NVIDIA (NVAPI, `nvapi64.dll` из драйвера, открытый заголовок NVIDIA под лицензией MIT):** переключатели `gpm` (режим питания «предпочтителен максимум производительности»), `lowlat` (максимум заранее отрисованных кадров = 1), `shader` (кэш шейдеров без ограничения). Это те же глобальные параметры драйвера, что в Панели управления NVIDIA; они сохраняются после перезагрузки и откатываются через историю. Идентификаторы и размер структуры сверены с заголовком.
- **Не пишутся программой, убраны из списка:** `boost`, `ppt`, `tlim`, `co`, `pbo`, `pl2`, `uvi` (регистры процессора, нужен драйвер ядра с платной подписью, возможен конфликт с античитами), `gtemp`, `refl`, `antil` (нет публичного интерфейса). Вместо них есть руководства.
- AMD-видеокарты: ничего не записывается (интерфейс ADLX не подключён, проверить его без карты AMD нельзя), доступно руководство.

## Руководства по подбору значений
На вкладке «Процессор» (все ПК и ноутбуки) и «Видеокарта» (настольные карты) есть сворачиваемая карточка. Выберите сокет или серию, затем модель: списки зависят от типа устройства (ноутбучные процессоры ПК не показываются). Установленная модель определяется сама. Для модели показана таблица «Безопасно / Для игр / Максимум», где менять (BIOS, Ryzen Master, Intel XTU, Панель управления NVIDIA, AMD Software, MSI Afterburner) и пошаговая инструкция. Кнопка «Открыть» запускает установленную официальную программу, иначе открывает страницу на сайте производителя.
- Процессоры: 172 модели, Ryzen от 1000 до новейших, Intel от 9-го поколения (данные `Data/cpus.json`).
- Видеокарты: 69 моделей, GeForce GTX 1060 и новее, Radeon RX 570 / Vega и новее (`Data/gpus.json`).
- Значения рассчитаны по правилам из паспортных данных (TDP, PPT, Tjmax, эталонная мощность платы), это ориентир, а не замеры вашего экземпляра. Руководство ничего не записывает.

## Окно «Нужна программа производителя»
Серый чип на строке («нужен драйвер» или «недоступно») можно нажать: откроется окно с названием параметра, вашим процессором или видеокартой, объяснением, зачем нужна программа, и ссылкой на официальный сайт производителя. Ссылка выбирается по определённому железу (Intel CPU → Intel XTU, AMD CPU → AMD Ryzen Master, NVIDIA GPU → драйвер NVIDIA, AMD GPU → драйвер AMD). Приложение открывает только адреса на доменах intel.com, amd.com и nvidia.com и ничего не скачивает само. Если у видеокарты NVIDIA нет библиотеки драйвера (nvml.dll), окно показывается при запуске.
У Intel XTU интерфейс командной строки убран в новых версиях (подтверждено ответом поддержки Intel), у AMD Ryzen Master я его не нашёл, поэтому управлять ими из Corvite нельзя. Поэтому для процессора есть руководство (см. выше), а серые строки процессора убраны.

## База чипов ОЗУ (этап 6)
`src/Corvite.Core/Data/ram_chips.json`: 17 ревизий (DDR4: Samsung B/C/D/E, SK hynix AFR/CJR/DJR/MFR, Micron Rev.E/B/J/R; DDR5: SK hynix A/M, Samsung B, Micron A). Значения собраны из открытых руководств оверклокеров и осторожно округлены: [ozgk/ddr4-oc-guide](https://github.com/ozgk/ddr4-oc-guide), [webpcdesigns DDR4](https://webpcdesigns.com/blog/ddr4-overclocking-guide), [webpcdesigns DDR5](https://webpcdesigns.com/blog/ddr5-overclocking-guide). Источники местами расходятся, поэтому у чипов с малым числом данных стоит метка «данных мало». Подсказка по номеру модели (`RamChips.DetectFromPartNumber`) только предлагает чип, пользователь подтверждает. Ссылка на Thaiphoon Burner ведёт на страницу каталога Softpedia (выбрана пользователем): сайт автора (softnology.biz) больше не работает, а `thaiphoonburner.com` подтвердить нельзя. Приложение открывает только домены производителей железа и эту страницу Softpedia.

## Релиз и обновления (этап 8)
- Релиз: `git tag v0.1.0` и `git push origin v0.1.0`. Workflow `release` собирает self-contained single-file `Corvite.exe`, из него делает `Corvite-Setup.exe` и portable zip и прикрепляет их к GitHub Release. Проверка сборки на каждый push: workflow `build`.
- Установщик: `Corvite-Setup.exe` это тот же единый файл, что и `Corvite.exe`. Если его имя начинается с `Corvite-Setup`, показывается окно установки (путь, язык программы RU / UA / EN, ярлык на рабочем столе, анимация логотипа), и файл копирует сам себя в `C:\Program Files\Corvite`, создаёт ярлыки и запись в «Приложениях». Удаление: `Corvite.exe --uninstall` (то же окно; можно вернуть исходные настройки Windows и, по желанию, удалить настройки и копию). Для проверки внешнего вида из обычной сборки: `Corvite.exe --install --dry-run` или `--uninstall --dry-run` (ничего не пишет). Установка работает только из опубликованного single-file, из папки сборки отказывается.
- Обновления: при запуске приложение один раз спрашивает GitHub о последнем релизе и, если версия новее, показывает плашку на «Обзоре» со ссылкой. Отключается в `%ProgramData%\Corvite\config.json`: `"CheckUpdates": false`. Velopack не используется: он ставит приложение в профиль пользователя и сам запускает его при обновлении, а Corvite требует права администратора (UAC при каждом таком запуске).
- Лицензии зависимостей: `THIRD-PARTY-NOTICES.md`.
