# Corvite

Десктопный оптимизатор Windows 11 для игр (C# / .NET 8 / WPF, MIT). Полное ТЗ: `TZ.md`. Эталон дизайна и текстов: `tools/prototype.html`.

## Сборка (на Windows 11, нужен .NET 8 SDK)
```
dotnet build Corvite.sln -c Release
```
Запуск (приложению нужны права администратора, из обычной консоли `dotnet run` не работает, ошибка 740):
```
Start-Process "src\Corvite.App\bin\Release\net8.0-windows10.0.22000.0\Corvite.exe" -Verb RunAs
```
Отладочный режим с демо-конфигурациями железа (6 конфигураций из прототипа на вкладке «Железо и частоты»):
```
Start-Process "src\Corvite.App\bin\Release\net8.0-windows10.0.22000.0\Corvite.exe" -ArgumentList "--demo" -Verb RunAs
```

> ⚠ Код написан без компиляции в среде разработки (нет .NET SDK). Этап 1 собран и проверен пользователем. Этапы 2 и 3 ещё не проверялись: возможны мелкие ошибки сборки.

## Датчики (этап 2)
Температура и частоты берутся из LibreHardwareMonitor. На части систем драйвер доступа к процессору заблокирован Windows или антивирусом: тогда температура CPU берётся из ACPI-зоны (на некоторых ноутбуках её нет) или показывается «—». Загрузка и ОЗУ работают без драйвера.

## Структура
- `src/Corvite.Core`: каталог параметров (`TweakCatalog.g.cs`, **генерируется** из прототипа), движок профилей/риска/эффекта (`ProfileEngine`), данные (`Data/*.json`: игры, тайминги ОЗУ, демо-железо).
- `src/Corvite.Hardware`: `HardwareDetector` (WMI: CPU, GPU, ОЗУ, плата, диск, ПК/ноутбук) и `SensorService` (LibreHardwareMonitor, ОЗУ, ACPI).
- `src/Corvite.App`: WPF, тема (`Theming/Theme.xaml`), шаблоны строк и страниц (`Views/Templates.xaml`), ViewModels, локализация (`Resources/Strings*.resx`, `Localization/Loc.cs`).
- `tools/gen.js`: перегенерирует каталог и `.resx` из `tools/prototype.html` (`node tools/gen.js tools/prototype.html .`).

Шрифты (Tektur, IBM Plex Sans, JetBrains Mono) нужно положить в `src/Corvite.App/Assets/Fonts` (см. README там).

## Этап 3: запись в Windows
- Приложение требует администратора. При первом запуске создаётся `%ProgramData%\Corvite\Backups\baseline.json` (исходные значения) до любых изменений.
- Перед первым применением за сеанс создаётся точка восстановления Windows (Windows разрешает одну в 24 часа, ошибка не критична).
- «Вернуть как было» откатывает последнее применение; «Вернуть исходные настройки» берёт baseline. Логи: `%ProgramData%\Corvite\Logs\corvite.log`.
- Безопасная проверка интерфейса без записи в систему: запуск с ключом `--dry-run`.
- Авто-откат: две подряд замеры CPU/GPU выше порога в течение 15 минут после применения отменяют последнее применение.
- Параметры защиты (порог, переключатели) пока не сохраняются между запусками.
