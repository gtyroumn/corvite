# Corvite

Десктопный оптимизатор Windows 11 для игр (C# / .NET 8 / WPF, MIT). Полное ТЗ: `TZ.md`. Эталон дизайна и текстов: `tools/prototype.html`.

## Сборка (на Windows 11, нужен .NET 8 SDK)
```
dotnet build Corvite.sln -c Release
```
Запуск (приложению нужны права администратора, из обычной консоли `dotnet run` не работает, ошибка 740):
```
Start-Process "src\Corvite.App\bin\Release\net8.0-windows10.0.22000.0\Corvite.exe" -Verb RunAs
```
Отладочный режим с демо-конфигурациями железа (6 конфигураций из прототипа на вкладке «Железо и частоты»):
```
Start-Process "src\Corvite.App\bin\Release\net8.0-windows10.0.22000.0\Corvite.exe" -ArgumentList "--demo" -Verb RunAs
```

> ⚠ Код написан без компиляции в среде разработки (нет .NET SDK). Этап 1 собран и проверен пользователем. Этапы 2 и 3 ещё не проверялись: возможны мелкие ошибки сборки.

## Датчики (этап 2)
Температура и частоты берутся из LibreHardwareMonitor. На части систем драйвер доступа к процессору заблокирован Windows или антивирусом: тогда температура CPU берётся из ACPI-зоны (на некоторых ноутбуках её нет) или показывается «—». Загрузка и ОЗУ работают без драйвера.

## Структура
- `src/Corvite.Core`: каталог параметров (`TweakCatalog.g.cs`, **генерируется** из прототипа), движок профилей/риска/эффекта (`ProfileEngine`), данные (`Data/*.json`: игры, тайминги ОЗУ, демо-железо).
- `src/Corvite.Hardware`: `HardwareDetector` (WMI: CPU, GPU, ОЗУ, плата, диск, ПК/ноутбук) и `SensorService` (LibreHardwareMonitor, ОЗУ, ACPI).
- `src/Corvite.App`: WPF, тема (`Theming/Theme.xaml`), шаблоны строк и страниц (`Views/Templates.xaml`), ViewModels, локализация (`Resources/Strings*.resx`, `Localization/Loc.cs`).
- `tools/gen.js`: перегенерирует каталог и `.resx` из `tools/prototype.html` (`node tools/gen.js tools/prototype.html .`).

Шрифты (Tektur, IBM Plex Sans, JetBrains Mono) нужно положить в `src/Corvite.App/Assets/Fonts` (см. README там).

## Этап 3: запись в Windows
- Приложение требует администратора. При первом запуске создаётся `%ProgramData%\Corvite\Backups\baseline.json` (исходные значения) до любых изменений.
- Перед первым применением за сеанс создаётся точка восстановления Windows (Windows разрешает одну в 24 часа, ошибка не критична).
- «Вернуть как было» откатывает последнее применение; «Вернуть исходные настройки» берёт baseline. Логи: `%ProgramData%\Corvite\Logs\corvite.log`.
- Безопасная проверка интерфейса без записи в систему: запуск с ключом `--dry-run`.
- Авто-откат: две подряд замеры CPU/GPU выше порога в течение 15 минут после применения отменяют последнее применение.
- Параметры защиты (порог, переключатели) пока не сохраняются между запусками.

## Во время игры (этап 4)
Список программ для «Закрывать фоновые приложения» лежит в `%ProgramData%\Corvite\kill-list.txt` (создаётся при первом запуске игры, по одному имени процесса в строке, `#` отключает строку). Закрытые программы запускаются снова после игры. Лимит фоновой нагрузки понижает приоритет чужих программ (до 24 % «ниже обычного», с 25 % «простой»), после игры приоритеты возвращаются. Если приложение закрылось аварийно во время игры, при следующем запуске оно вернёт службы и уведомления.

## Этап 5: что сделано и что нет
- **NVIDIA (NVML, `nvml.dll` из драйвера):** `gpow`, `gcore`, `gmem`. Настройки NVML сбрасываются после перезагрузки или перезапуска драйвера. Смещение памяти считается в «эффективных» МГц, как в MSI Afterburner (в NVML вдвое меньше). На многих ноутбуках драйвер запрещает такие изменения: тогда строка остаётся серой «недоступно».
- **Не реализованы** (серые, «нужен драйвер»): `boost`, `ppt`, `tlim`, `co`, `pbo`, `pl2`, `uvi` (нужен доступ к регистрам процессора или сторонняя утилита; без возможности проверить на железе это небезопасно), `gtemp`, `lowlat`, `shader`, `gpm`, `antil`, `refl` (настройки закрытого профиля драйвера NVIDIA/AMD без публичного интерфейса).
- AMD-видеокарты: все GPU-твики серые.

## Окно «Нужна программа производителя»
Серый чип на строке («нужен драйвер» или «недоступно») можно нажать: откроется окно с названием параметра, вашим процессором или видеокартой, объяснением, зачем нужна программа, и ссылкой на официальный сайт производителя. Ссылка выбирается по определённому железу (Intel CPU → Intel XTU, AMD CPU → AMD Ryzen Master, NVIDIA GPU → драйвер NVIDIA, AMD GPU → драйвер AMD). Приложение открывает только адреса на доменах intel.com, amd.com и nvidia.com и ничего не скачивает само. Если у видеокарты NVIDIA нет библиотеки драйвера (nvml.dll), окно показывается при запуске.
У Intel XTU интерфейс командной строки убран в новых версиях (подтверждено ответом поддержки Intel), у AMD Ryzen Master я его не нашёл, поэтому управлять ими из Corvite нельзя. Параметры процессора остаются серыми.

## База чипов ОЗУ (этап 6)
`src/Corvite.Core/Data/ram_chips.json`: 17 ревизий (DDR4: Samsung B/C/D/E, SK hynix AFR/CJR/DJR/MFR, Micron Rev.E/B/J/R; DDR5: SK hynix A/M, Samsung B, Micron A). Значения собраны из открытых руководств оверклокеров и осторожно округлены: [ozgk/ddr4-oc-guide](https://github.com/ozgk/ddr4-oc-guide), [webpcdesigns DDR4](https://webpcdesigns.com/blog/ddr4-overclocking-guide), [webpcdesigns DDR5](https://webpcdesigns.com/blog/ddr5-overclocking-guide). Источники местами расходятся, поэтому у чипов с малым числом данных стоит метка «данных мало». Подсказка по номеру модели (`RamChips.DetectFromPartNumber`) только предлагает чип, пользователь подтверждает. Ссылка на Thaiphoon Burner ведёт на страницу каталога Softpedia (выбрана пользователем): сайт автора (softnology.biz) больше не работает, а `thaiphoonburner.com` подтвердить нельзя. Приложение открывает только домены производителей железа и эту страницу Softpedia.
